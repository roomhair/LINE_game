# 今日のLINEゲーム

LINE風のトーク画面で、次々に届く「今日の〇〇」グループのメッセージに返信し、
返信の面白さでポイントを競う短編コミュニケーションゲームです。全5回の返信で総合評価（最高500pt）が決まります。

> 実在のLINEアカウント・サービスとは一切連携しない、LINE風のゲーム画面です。

## 遊び方
1. 名前とテーマ（おまかせ／飯／お出かけ／恋愛／仕事／友達／趣味・その他／ごちゃまぜ）を選んでスタート
2. 通知とともにグループにLINEが届くので、自由に返信を入力して送信（Enterで送信、Shift+Enterで改行）
3. メンバーのリアクションと、4項目（面白さ・気の利き・意外性・空気読み 各25点）の採点が表示されます
4. 5回返信すると、ランク・ベスト返信・振り返りが表示されます

## 審査モード
| モード | 条件 | 内容 |
| --- | --- | --- |
| 🤖 AI審査 | Vercel に `ANTHROPIC_API_KEY` を設定 | Claude が返信を採点し、メンバーの自然な反応を生成。2回目以降の会話の書き出しも毎回AIが新しく作ります |
| 📋 かんたん審査 | キー未設定・API失敗時 | ブラウザ内のルールベース採点＋定型リアクション（オフラインでも遊べる） |

AIの呼び出しに失敗した場合も自動でかんたん審査に切り替わるので、ゲームは止まりません。

## Vercel へのデプロイ
1. https://vercel.com/new でこの GitHub リポジトリを Import
2. Framework Preset は **Other**、ビルド設定はすべてデフォルトのまま（ビルド不要）
3. （任意）Settings → Environment Variables に `ANTHROPIC_API_KEY` を追加すると AI審査モードになります
   - 使用モデルを変えたい場合は `LINE_GAME_MODEL` を設定（既定: `claude-opus-5-5`）
4. Deploy → `https://<プロジェクト名>.vercel.app` で公開されます

※ `/api/*` は公開エンドポイントなので、キーを設定する場合は Anthropic Console で利用上限を設定しておくのがおすすめです。

## ローカルで動かす
```bash
npx serve .          # かんたん審査モードで起動
npx vercel dev       # API込みで起動（.env.local に ANTHROPIC_API_KEY）
```

## 構成
```
index.html / style.css     画面（タイトル・トーク・結果）
js/data.js                 カテゴリ・グループ・会話シナリオ・ランク定義
js/scorer.js               ローカル採点とリアクション
js/game.js                 ゲーム進行・描画
api/judge.js               AI採点＋メンバーの反応生成
api/opener.js              AIによる会話の書き出し生成
api/status.js              AI審査が使えるかの確認
```

### グループ・テーマの追加
`js/data.js` の `CATEGORIES[].groups` に `{ name, icon, s: [シナリオ] }` を追加するだけで出題されます。
カテゴリ自体を追加すればタイトル画面のテーマ選択にも自動で並びます。
`GEN_TOPICS` に単語を足すと「今日の〇〇」グループがランダム生成されます（ごちゃまぜ・グループ不足時に登場）。
